WinIPSに合わせて画面を小さくしました。

- 表示領域を404×162ピクセルに縮小。
- 「操作」の選択、2つのファイル欄、適用／作成ボタンの構成。
- 出力先欄、説明文、ログ欄、保存先フォルダーボタンを削除。
- 作成形式は「操作」からBPS／UPS／IPSを選択。
- 保存先は自動生成し、完了・エラーはダイアログで表示。
- 同名ファイルがあれば連番を付け、元ROMと既存ファイルを保持。

IPS／BPS／UPSの作成・適用、BPS／UPSの16 MiB→32 MiB拡張、CRC32検証に対応しています。

`MulchPatcher.exe` をダウンロードして実行してください。Windows 10／11、.NET Framework 4.8。
